# Turn-Based MCTS Implementation

## Overview

This document describes the turn-based Monte Carlo Tree Search (MCTS) implementation for Zatikon, where MCTS nodes represent complete turns (sequences of actions) rather than individual actions.

## Key Design Decisions

1. **MCTS Nodes = Full Turns**: Each node in the MCTS tree represents a complete turn (sequence of actions ending with END_TURN).

2. **Action-Level Policy Learning**: While MCTS explores at the turn level, we record training data at the action level. Each action in a turn gets the turn's final value.

3. **Turn Generation**: Turns are generated by sampling actions from the network policy until END_TURN is selected.

4. **Deterministic Revisits**: When revisiting a node, we replay the same cached turn sequence to ensure consistency.

## Architecture

### TurnNode Class

```python
class TurnNode:
    action_sequence: List[Tuple[int, int, int]]  # Actions in this turn
    state_end_encoded: np.ndarray  # Encoded state after turn
    state_key: str  # Key for state after turn
    visits: int  # Number of times this node was visited
    total_value: float  # Sum of values from simulations
    children: List[TurnNode]  # Different turns from this state
    cached_value: Optional[float]  # Value from network evaluation
```

### MCTS Class

**Key Methods**:

- `generate_turn(game, temp)`: Generates a complete turn by sampling actions from network policy
- `run(game)`: Runs MCTS simulations and returns action-level policy
- `_simulate(game, node)`: Performs one MCTS simulation from a turn node

### MCTS Flow

1. **Initialization**: Create root node with initial turn
2. **Simulation**: 
   - Select child node using UCB
   - Replay child's turn sequence to reach its state
   - Continue simulation from child's state
3. **Expansion**: When a node has no children, generate a new turn
4. **Backpropagation**: Update node statistics with simulation value
5. **Policy Extraction**: Aggregate visit counts over all actions in all explored turns

## Turn Generation

Turns are generated by:

1. Starting from turn-start state
2. Getting network policy for current state
3. Masking illegal actions
4. Sampling action from policy (with temperature)
5. Applying action to game state
6. Repeating until END_TURN is selected or game ends

## Action-Level Learning

During self-play:

1. MCTS explores turns (for efficiency)
2. For each turn, we record:
   - State before each action
   - Action taken
   - Policy at that state
   - Turn's final value (assigned to all actions in turn)
3. Training data: `(state_before_action, policy, turn_value)`

## Value Evaluation

- **During Turn**: Evaluate at turn end (after END_TURN)
- **Terminal States**: Use actual game outcome (+1 win, -1 loss, 0 draw)
- **Non-Terminal**: Use network value estimate

## Advantages

1. **Efficiency**: Fewer nodes to explore (turns vs actions)
2. **Coherence**: Explores complete turn sequences
3. **Learning**: Still learns action-level policies
4. **Consistency**: Cached turns ensure deterministic revisits

## Implementation Details

### Game State Copying

Uses `copy.deepcopy()` to create game copies for MCTS simulation. This ensures the original game state is not modified during exploration.

### State Key

State keys are based on:
- Current player
- Turn number
- Commands left for both castles
- Unit positions (team, location, unit_id)

### UCB Selection

Standard UCB1 formula:
```
UCB = Q + C * sqrt(ln(N_parent) / (1 + N_child))
```

Where:
- Q = average value of child
- C = exploration constant (CPUCT = 1.5)
- N_parent = visits to parent
- N_child = visits to child

### Policy Extraction

Action-level policy is extracted by:
1. Counting visits to each action across all explored turns
2. Normalizing to create probability distribution
3. Masking to only include legal actions

## Usage

```python
# Create MCTS
mcts = MCTS(net, n_simulations=200)

# Run MCTS from current game state
pi, root_q, q_values = mcts.run(game)

# pi: action-level policy (np.array of size ACTION_SIZE)
# root_q: root Q-value
# q_values: per-action Q-values
```

## Training Data Format

Self-play returns:
```python
examples = [
    (state_before_action, policy, value),
    ...
]
```

Where:
- `state_before_action`: Encoded game state before action
- `policy`: Action-level policy from MCTS
- `value`: Turn value (or actual outcome if game ended)
